# 拾光 · Windows 便携版

1. 将完整程序文件夹解压到自己的可写目录。
2. 双击 `Daynote.exe`。无需另装 Node.js 或数据库。
3. 点击「新建待办」记录事情，在卡片中设置日期时间提醒。

关闭窗口后程序在托盘继续运行。双击托盘图标恢复窗口；托盘菜单中的「退出软件」停止程序和提醒。

在「偏好设置」中选择主题色、深色外观，以及「开机自启动」。自启动默认关闭；开启后登录 Windows 自动在托盘运行，不弹出主窗口。

任务位于程序同目录的 `data/tasks.json`，有效备份为 `data/tasks.backup.json`。移动程序请保留整个文件夹。删除或更新程序前先在界面中导出 JSON 备份。若开启自启动，移动前先关闭，在新位置打开后重新开启。

程序可离线运行，不需要账号。关机、未登录或完全退出期间不能提醒；休眠恢复或下次启动时检查遗漏提醒。系统通知是否显示取决于 Windows 通知与勿扰设置。

这是早期版本，未提供 Windows 安装器和程序签名。标准发行包不携带开发者的个人待办；第一次打开会显示少量无提醒的示例任务。
